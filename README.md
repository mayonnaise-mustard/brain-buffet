# Brain Buffet

Brain Buffet is a zombie game I developed in Godot for my high school senior project. It gave me hands-on experience with game development, debugging, and bringing separate game components together.

## Built With

- Godot Engine
- GDScript

## What I Worked On

I worked on integrating the game’s graphics, hitboxes, and other components so they functioned together as intended.

One of the biggest challenges was identifying the source of problems when multiple components affected one another. To resolve these issues, I researched possible solutions, tested individual elements, and adjusted my code and settings.

## What I Learned

This project helped me develop my ability to:

- Break technical problems into smaller, manageable parts.
- Research and test solutions independently.
- Use unsuccessful attempts to guide further troubleshooting.
- Stay focused and follow through on a challenging project.

## Running the Project

1. Download or clone this repository.
2. Open Godot and import the project using its `project.godot` file.
3. Open the project and run it from the editor.
